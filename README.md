# Clean GPS

แอพแผนที่ GPS แบบคลีน เบา ไม่มี build step ไม่ต้องใช้ API key

## ฟีเจอร์
- ไอคอนตำแหน่งของเรา: ลูกศร / จุด / อีโมจิ / อัปโหลดรูปเอง + เลือกสีได้ (จำค่าไว้ในเครื่อง)
- แตะแผนที่เพื่อปักปลายทาง → เห็นระยะทาง/เวลา → กด "เริ่ม"
- แสดง % ความคืบหน้าจากต้นทางถึงปลายทาง (ทศนิยม 1 ตำแหน่ง, นับขึ้นนุ่มๆ) + เส้นทางส่วนที่ผ่านแล้วจะจางลง
- ล็อกมุมกล้อง (ปุ่มลูกศรบนขวา): กล้องตามตำแหน่ง หันตามทิศที่เราหัน
  - ซูมออก/หมุน/เลื่อนแผนที่เองได้ แล้วอีก 5 วินาที (มีวงแหวนนับถอยหลัง) กล้องจะกลับมาที่ตำแหน่ง ทิศ และระดับซูมเดิมเอง
  - ปุ่ม + / − ขณะล็อก = เปลี่ยนระดับซูมที่ "จำ" ไว้
- ไม่ให้จอดับระหว่างนำทาง (Wake Lock)

## รันในเครื่อง
```
python3 -m http.server 8000
```
แล้วเปิด http://localhost:8000 (localhost ใช้ GPS ได้)

ลองบนคอมโดยไม่ต้องขยับจริง: เปิด `http://localhost:8000/?demo` แล้วแตะแผนที่ → กดเริ่ม จะมีตำแหน่งจำลองวิ่งตามเส้นทาง

## ขึ้น GitHub Pages
1. push ไฟล์ทั้งหมดขึ้น repo
2. Settings → Pages → Deploy from branch → `main` / root
3. เปิดลิงก์ `https://<user>.github.io/<repo>/` บนมือถือ (ต้องเป็น https เพื่อใช้ GPS)
4. เมนูเบราว์เซอร์ → "Add to Home Screen" จะได้เป็นแอพเต็มจอ

## เครดิต / ข้อควรรู้
- แผนที่: [MapLibre GL JS](https://maplibre.org) + [OpenFreeMap](https://openfreemap.org) (positron) ฟรี ไม่ต้องใช้ key
- เส้นทาง: OSRM public demo server (`router.project-osrm.org`) เหมาะกับใช้ส่วนตัวเบาๆ; ถ้าล่มจะใช้เส้นตรงแทนอัตโนมัติ
- ทิศขณะยืนนิ่งใช้เข็มทิศมือถือ (iOS จะขออนุญาตตอนแตะครั้งแรก) ขณะเคลื่อนที่ใช้ทิศจาก GPS
